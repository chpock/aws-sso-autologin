# Linting Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `leyline:subagent-driven-development` (recommended) or `leyline:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить линтер ruff в проект с интеграцией в Makefile и автоматическим запуском при тестировании

**Architecture:** Использовать ruff как современный заменитель flake8+black+isort. Конфигурация через pyproject.toml, интеграция через Makefile targets.

**Tech Stack:** ruff (latest)

**Spec references:**
- Product spec: `docs/leyline/specs/2026-05-10-linting-design.md`
- UX spec: `docs/leyline/design/2026-05-10-linting-ux.md`
- Baseline: `docs/leyline/plans/2026-05-10-linting-baseline.md`

**Surfaces:** developer-facing

**Files:**
- Modify: `pyproject.toml` - добавить ruff в dev-зависимости и настроить
- Modify: `Makefile` - заменить заглушку lint на реальную команду и добавить lint в test

### Task 2: Configure ruff in pyproject.toml

**Files:**
- Modify: `pyproject.toml` (добавить секцию `[tool.ruff]`)

**Steps:**

- [ ] **Step 1: Add ruff configuration**

```toml
[tool.ruff]
target-version = "py311"
line-length = 88

[tool.ruff.lint]
select = [
    "E",   # pycodestyle errors
    "F",   # Pyflakes
    "W",   # pycodestyle warnings
    "I",   # isort
    "N",   # pep8-naming
    "UP",  # pyupgrade
]
ignore = []

[tool.ruff.lint.pydocstyle]
convention = "google"

[tool.ruff.format]
quote-style = "double"
indent-style = "space"
```

- [ ] **Step 2: Verify configuration**

```bash
grep -A 20 "tool.ruff" pyproject.toml | head -25
# Expected: Shows ruff configuration sections
```

- [ ] **Step 3: Commit**

```bash
git add pyproject.toml && git commit -m "config: add ruff configuration"
```

### Task 3: Update Makefile lint target

**Files:**
- Modify: `Makefile` (заменить заглушку lint)

**Steps:**

- [ ] **Step 1: Read current Makefile**

```bash
cat Makefile | grep -A 3 "^lint:"
```

- [ ] **Step 2: Replace lint target**

Заменить:
```makefile
lint: venv
	@printf "No linter configured yet.\n"
```

На:
```makefile
lint: venv
	@"$(VENV)/bin/ruff" check .
	@"$(VENV)/bin/ruff" format --check .
```

- [ ] **Step 3: Verify the change**

```bash
cat Makefile | grep -A 3 "^lint:"
# Expected: Shows ruff check and format commands
```

- [ ] **Step 4: Commit**

```bash
git add Makefile && git commit -m "build(make): implement lint target with ruff"
```
